# 📒 Agenda Simples v1.2

Projeto desenvolvido em **linguagem C** com o objetivo de praticar conceitos fundamentais de programação, estruturas de dados e organização de código.

Esta versão é uma evolução da **Agenda Simples v1.0**, adicionando o registro automático da **data e hora de cadastro** de cada contato.

---

## 🚀 Sobre o projeto

A Agenda Simples é um sistema de gerenciamento de contatos desenvolvido em C, permitindo cadastrar, consultar, editar e excluir pessoas.

O projeto foi criado como parte da minha jornada de aprendizado em programação, buscando transformar conceitos estudados em aplicações práticas.

---

## ✨ Funcionalidades

* ✅ Cadastro de pessoas
* ✅ Listagem de contatos cadastrados
* ✅ Pesquisa por CPF
* ✅ Busca por nome
* ✅ Edição de informações
* ✅ Exclusão de contatos
* ✅ Validação de CPF duplicado
* ✅ Registro automático da data e hora do cadastro

---

## 🆕 Novidades da versão 1.1

Nesta atualização foi implementado:

* 📅 Registro da data de criação do contato
* ⏰ Armazenamento do horário do cadastro
* 🕒 Uso da biblioteca padrão `time.h`
* 📌 Integração da nova informação dentro da estrutura `struct Pessoa`

Exemplo:

```
Nome: Lucas Queiroz
Telefone: (00) 00000-0000
CPF: 000.000.000-00
Email: exemplo@email.com
Data de cadastro: 02/08/2026 13:40
```
